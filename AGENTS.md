# AGENTS.md

## Project

This is a countertop estimator application.

Accuracy, pricing integrity, quote safety, and maintainability are the highest priorities.

The system manages:
- quotes
- quote line items
- pricing calculations
- orders
- admin-managed pricing

## Package Manager

This repository uses pnpm only.

Use:

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm check
pnpm test
pnpm build
```
